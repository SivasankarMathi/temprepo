# ShopVerse — React eCommerce (UI Only)

A frontend-only eCommerce application inspired by Amazon and Flipkart.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router v6
- Context API (global state)

## Features

- **Home Page** — hero banner, category grid, featured products, deals
- **Product Listing** — category filter, sorting, search, pagination
- **Product Details** — full product info, quantity selector, related products
- **Cart** — quantity controls, order summary with shipping & tax
- **Checkout** — shipping form and order confirmation
- **User Profile** — editable profile, order history
- **Wishlist** — saved items
- **Admin Dashboard** — inventory stats, add/delete products

## Data

40 mock products across 8 categories: Mobiles, Laptops, Audio, Wearables,
Fashion, Home Appliances, Books, and Sports.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
