# Login Page

A simple, responsive login page with modern styling and basic functionality.

## Features

- Clean, modern UI with gradient background
- Responsive design that works on mobile and desktop
- Form validation
- Forgot password and sign up links
- Smooth animations and transitions

## Files

- `login.html` - Main login page structure
- `styles.css` - Styling for the login page
- `script.js` - JavaScript functionality for form handling

## Usage

Simply open `login.html` in a web browser to view the login page.

For testing purposes:
- Username: `admin`
- Password: `password`

## Customization

You can easily customize the colors, fonts, and layout by modifying the CSS file.
