# Syncfusion React Pie Chart

Simple Vite + React app that renders a **Syncfusion Accumulation (Pie) Chart** with dummy sales data.

Built using guidance from [ai.syncfusion.com](https://ai.syncfusion.com) (React platform index + Accumulation Chart skill).

## Stack

- React 18 + Vite
- `@syncfusion/ej2-react-charts` (`AccumulationChartComponent`, `PieSeries`)
- Material theme CSS

## Setup

```bash
npm install
```

Optional license (removes trial banner):

1. Copy `.env.example` to `.env`
2. Set `VITE_SYNCFUSION_LICENSE_KEY` from [Syncfusion claim license key](https://www.syncfusion.com/account/claim-license-key)

```bash
npm run dev
```

```bash
npm run build
```

## Chart data

Dummy categories in `src/App.jsx`: Electronics, Clothing, Home & Garden, Sports, Books.
