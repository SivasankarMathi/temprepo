# Glossary

Terms used in this project, one line each. Code, specs and reviews use these words.

| Term | Meaning |
|---|---|
| Brand panel | The gradient column beside the form that explains the product. It disappears on small screens. |
| Demo account | The single hard-coded credential pair that the sign-in form accepts in this demo. |
| Field error | A message shown under one input, tied to that input with `aria-describedby`. |
| Sign in | Submitting valid credentials to reach the workspace. |
| Workspace | The Acme product area that a signed-in user reaches from the sign-in page. |
